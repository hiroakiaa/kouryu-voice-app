# 退室操作・タブ配色 改善レポート（2026-10-06）

## 診断データの評価

- 接続完了は約0.5秒で、目立つ接続遅延はありません。
- WebRTC品質は good、RTT 4.5ms、jitter 1ms、packet loss 0%、経路は host → host でした。
- 自動復旧は0回で、通話中の回線は安定していました。
- 終了後は listener 0 / timer 0 / peer 0 で、後処理は正常です。
- この通話の利用相当額は約0.026円、継続時は約0.0025円/分です。これは診断上の概算で、無料枠・請求単位・為替により実際の請求額とは異なります。

## 改善したこと

- iPhoneなどのタッチ端末では、退室ボタンの短いタップを pointerup で直接受け取るようにしました。
- その直後に発生する click は終了処理中フラグで止め、二重実行しません。
- 指が12pxより大きく動いた場合はスクロール操作とみなし、誤退室を防ぎます。
- 次回の診断データへ退室操作回数と入力経路（touch-pointer / click）を追加しました。
- メインタブ、電話・連絡のサブタブ、選択ボタン、スクロールバーをアプリ共通の色変数へ統一しました。
- `callTips` にタッチ端末の退室動作を追記しました。

## 費用への影響

端末内の入力処理とCSSのみの変更です。Firestore、TURN、外部APIの利用は増えないため、運営費への追加影響はありません。

## 確認内容

- タッチ操作の最初の短いタップで退室処理を開始
- clickとの二重実行防止
- スクロール中の誤退室防止
- タブ配色とスクロールバーの共通テーマ適用
- rootとvoice-standaloneの一致
- 全自動テスト
