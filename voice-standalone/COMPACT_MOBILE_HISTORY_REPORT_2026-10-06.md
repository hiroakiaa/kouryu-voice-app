# スマホ履歴カード コンパクト化レポート（2026-10-06）

## 改善内容

- 狭い画面では履歴カードを「人物情報」と「操作」の2段構成にしました。
- 日付と時刻を、発信・着信・呼び出し終了などの結果の直下へ移動しました。
- 削除・連絡・電話ボタンをカード下部の横一列へ配置しました。
- 未登録の相手には電話帳登録も同じ操作列へ収めます。
- 余白、文字サイズ、ボタン高をスマホ向けに縮め、タップ領域は42px以上を保ちます。
- 541px以上では、従来の情報量を保った横並びレイアウトを使用します。

## 診断

`metricsOutput` の `phoneNavigation` に `compactMobileHistory` と `historyActionsInline` を追加しました。

## 費用

表示と配置だけの変更であり、Firestore、TURN、AI API の追加費用はありません。
